# Employee Database Manager

Простая консольная программа на Go для работы с базой данных сотрудников. Умеет искать, удалять и изменять данные через PostgreSQL.

## Возможности

- **Поиск сотрудников** по ID, имени, фамилии, должности
- **Сортировка** по зарплате, алфавиту, времени в компании
- **Удаление** записей по ID, имени или фамилии
- **Изменение** данных: зарплата, имя, фамилия, должность
